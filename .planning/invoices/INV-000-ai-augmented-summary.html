Why three tiers?

Standard rate ($4,627.50) — what a comparable engagement carries when delivered by human engineers at blended Jr/Mid/Sr rates ($85 / $125 / $175 per hour). This is the figure used across the ledger, invoices, and value-sheet for value-translation purposes. It represents the market price of the outputs, independent of how they were produced.

AI-augmented rate ($462.75) — what this engagement reasonably costs when an AI-augmented workflow is the delivery method. The 1/10 multiplier reflects observed velocity: same outputs, smaller calendar window, lower opportunity cost. This is the rate Macks Studios would charge for similar AI-augmented work going forward, when not delivered pro bono.

Billed to Outerfields ($0.00) — the actual amount invoiced for this engagement. Pro bono. The two figures above remain in the document so the engineering value is visible and the work is reusable as a reference for future paid engagements.

What "AI-augmented" actually means here

  • Specification authoring — Claude drafts the spec; Max reviews and corrects.
  • Implementation — Claude writes code against the spec; Max approves diffs, catches scope creep, surfaces real-world deviations.
  • Verification — Tests run locally and in CI. Failures get fixed before commits land. Same standard as any human engagement.
  • Documentation — Every PR ships a ledger entry. No "AI wrote this and ran" — every decision has a written rationale.
  • Direction — Max sets goals, makes priority calls, decides scope cuts, and is responsible for the output. The AI accelerates; the engineer accountable for what ships is Max Stern.

The AI tooling cost (API usage, Claude Code subscription) is absorbed by Macks Studios. Not a line item on this or any future invoice.
