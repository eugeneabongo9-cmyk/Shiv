6. Cache architecture — THE GAP

graph TB REQ(["600+ concurrent users"]) --> L1 L1["L1 CDN · static assets 🟢 auto"] --> L2 L2["L2 setHeaders · public reads 🔴"] --> L3 L3["L3 Cache API · catalog 🔴"] --> L4 L4["L4 KV · tier + tracker 🔴"] --> D1[("D1 source of truth 🟢")]
Why it's a blocker: dashboard load = 3–5 D1 reads × 600 users = ~3k reads/min just for hydration. D1 will throttle under load test.
Targets: members.tier lookup (L4 KV), course catalog (L3 Cache API), tracker count (L4 KV write-through).
