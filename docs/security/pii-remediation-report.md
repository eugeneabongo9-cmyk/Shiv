## 4. Protections implemented

### 4.1 `.gitignore` (exact additions)

```
*.db / *.db-wal / *.db-shm / *.sqlite / *.sqlite3
data/
founding-members.sql
d1-paste-chunks/
buyers.csv / buyers.sql / *-purchasers*.csv
exports/ / wc-export/

audit-report.html
.claude/settings.local.json
```

### 4.2 Pre-commit hook

`.husky/pre-commit` now runs `node scripts/guard-no-pii.mjs` before `pnpm check` and `lint-staged`.

`scripts/guard-no-pii.mjs` blocks staged files matching:

- Blocked path patterns (`.db`, `data/`, `d1-paste-chunks/`, etc.)
- Non-allowlisted `.csv` paths
- `INSERT INTO member_imports … VALUES (… 'email@domain' …)` outside allowlisted generator/test paths
- Non-allowlisted email domains in `.sql`/`.csv`/`.json`/`.html`/`.xml`

### 4.3 CI

New job `pii-scan` in `.github/workflows/ci.yml` runs `pnpm verify:no-pii` on every PR and push to `main`.

### 4.4 Secret / PII scanning patterns

`.gitleaks.toml` — rules for bulk `member_imports` INSERTs, WC CSV headers, founding-member export filenames, with allowlists for migrations and synthetic fixtures.

### 4.5 Verification scripts

| Script                  | Command                                                     |
| ----------------------- | ----------------------------------------------------------- |
| Tracked-file scan       | `pnpm verify:no-pii`                                        |
| Include local artifacts | `pnpm verify:no-pii:worktree`                               |
| Local purge (dry-run)   | `pwsh -File scripts/purge-local-pii-artifacts.ps1`          |
| Local purge (execute)   | `pwsh -File scripts/purge-local-pii-artifacts.ps1 -Execute` |

## 5. Git history remediation plan (`git-filter-repo`)

### 5.1 Scope decision

| Item                                    | Action                 | Rationale                                                       |
| --------------------------------------- | ---------------------- | --------------------------------------------------------------- |
| Real customer emails in history         | **No action required** | `git log -S "skye@graciemilwaukee.com"` returned zero commits   |
| `scripts/fixtures/wc-buyers-sample.csv` | **Optional scrub**     | Synthetic `@example.com` data only; hygiene / policy compliance |

### 5.2 Procedure (optional CSV history scrub)

**Prerequisites:** `pip install git-filter-repo`, full repo backup, coordinate with all collaborators.

```bash
# 1. Backup
git clone --mirror git@github.com:<org>/shivworks-network.git shivworks-network-mirror-backup.git

# 2. Clone fresh working copy for rewrite
git clone git@github.com:<org>/shivworks-network.git shivworks-network-scrub
cd shivworks-network-scrub

# 3. Remove file from all history
git filter-repo --path scripts/fixtures/wc-buyers-sample.csv --invert-paths

# 4. Validate
git log --all --oneline -- scripts/fixtures/wc-buyers-sample.csv   # must be empty
gitleaks detect --source . --redact --verbose
pnpm verify:no-pii

# 5. Force-push (coordinate freeze window)
git push --force-with-lease --all
git push --force-with-lease --tags
```

### 5.3 Validation procedure (post-rewrite)

```bash
pnpm verify:no-pii
gitleaks detect --source . --config .gitleaks.toml --redact
git log --all -S "INSERT INTO member_imports" --oneline -- "*.sql" "*.csv"
# Expect only generator source files, not data dumps
```

### 5.4 Rollback procedure

1. **Before force-push:** Abort — discard scrub clone; mirror backup untouched.
2. **After force-push:** Restore from mirror:
   ```bash
   git clone shivworks-network-mirror-backup.git restore-repo
   cd restore-repo
   git push --force-with-lease --all origin
   git push --force-with-lease --tags origin
   ```
3. **Collaborators after rewrite:** `git fetch origin && git reset --hard origin/main` (re-clone preferred).
4. **Production D1:** Unaffected — history rewrite is git-only.

## 7. Security validation checklist

### Pre-merge (every PR)

- [ ] `pnpm verify:no-pii` passes
- [ ] `node scripts/guard-no-pii.mjs` passes on staged changes
- [ ] PR diff contains no `*.db`, `*.csv` exports, `founding-members.sql`, `d1-paste-chunks/`
- [ ] PR template PII checkbox confirmed

### Post-remediation (one-time)

- [ ] Local artifacts purged (`pnpm verify:no-pii:worktree` shows zero warnings)
- [ ] `.gitignore` covers all export paths (§4.1)
- [ ] CI `pii-scan` job green on `main`
- [ ] (Optional) `git filter-repo` completed for `wc-buyers-sample.csv`
- [ ] (Optional) `gitleaks detect` clean on full history
- [ ] Collaborators notified if history was rewritten
